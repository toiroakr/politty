Add `politty/standard` for synchronous Standard Schema validators with a Standard JSON Schema input converter. Infer CLI arguments, help, and completion from the input schema, and accept optional CLI metadata per field through `standardArgs()`. Support unions, exclusive unions, object intersections, nested output with `unflatten()`, and the Standard adapter’s docs, completion, prompt, skill, agent, compile-cache, and Vite entry points.
